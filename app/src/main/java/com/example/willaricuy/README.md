# Código Kotlin de Willaricuy

- `MainActivity.kt`: inicia la app, conecta las tarjetas y abre Perfil mediante un Intent.
- `ConfiguracionActivity.kt`: maneja las filas de configuración y SharedPreferences.
- `VistaDiscreta.kt`: comparte la vista Ocultar entre las dos Activities.

Empieza por `onCreate`, identifica los IDs de `findViewById` y busca los mismos IDs en `res/layout`. Los comentarios explican el propósito de las partes principales.

El recorrido completo está en `docs/RECORRIDO_DEL_CODIGO.md`, desde la raíz del proyecto.
