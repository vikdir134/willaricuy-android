# Recursos del diseño

- `layout`: Inicio, Configuración y las tres partes compartidas: encabezado, navegación y vista discreta.
- `values/strings.xml`: textos visibles y opciones de los diálogos. Cambia aquí el texto Prueba.
- `values/colors.xml`: colores del prototipo.
- `values/themes.xml`: tipografía, tema y estilos de botones y filas.
- `drawable`: iconos XML y fondos; `drawable-nodpi`: logo.
- `font`: archivos de Inter y Nunito; sus licencias están en la raíz.
- `values-v23` y `values-v27`: ajustes de las barras del sistema para esas versiones o superiores.
- `xml`: reglas de respaldo de los datos locales.

Para explicar una pantalla, muestra su XML y después la Activity que utiliza sus IDs. Los `include` permiten reutilizar una misma parte visual en ambas pantallas.
